# Задачи — Особенности класса String

---

### Задача 1. Склейка строк через StringBuilder

Реализуй метод, который принимает массив строк и возвращает их склейку через `StringBuilder`.

```java
String join(String[] words)
```

| words | результат |
|-------|-----------|
| `["Hello", "World"]` | `"HelloWorld"` |
| `["a", "b", "c"]` | `"abc"` |
| `["one"]` | `"one"` |

---

### Задача 2. Склейка с разделителем

Реализуй метод, который склеивает массив строк через разделитель `separator`.

```java
String joinWithSeparator(String[] words, String separator)
```

| words | separator | результат |
|-------|-----------|-----------|
| `["a", "b", "c"]` | `", "` | `"a, b, c"` |
| `["Hello", "World"]` | `" "` | `"Hello World"` |
| `["one"]` | `"-"` | `"one"` |

---

### Задача 3. Повторить строку N раз

Реализуй метод, который возвращает строку, повторённую `n` раз, используя `StringBuilder`.

```java
String repeat(String s, int n)
```

| s | n | результат |
|---|---|-----------|
| `"ab"` | `3` | `"ababab"` |
| `"x"` | `5` | `"xxxxx"` |
| `"hi"` | `1` | `"hi"` |

---

### Задача 4. Перевернуть строку

Реализуй метод, который возвращает строку в обратном порядке, используя `StringBuilder`.

```java
String reverse(String s)
```

| s | результат |
|---|-----------|
| `"Hello"` | `"olleH"` |
| `"Java"` | `"avaJ"` |
| `"a"` | `"a"` |

---

### Задача 5. Подсчёт символов

Реализуй метод, который строит строку вида `"Символов: N"` где N — длина входной строки, используя `StringBuilder`.

```java
String charCount(String s)
```

| s | результат |
|---|-----------|
| `"Hello"` | `"Символов: 5"` |
| `""` | `"Символов: 0"` |
| `"ab"` | `"Символов: 2"` |
