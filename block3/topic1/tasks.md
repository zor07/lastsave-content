# Задачи — Класс String, основы

---

### Задача 1. Длина строки

Реализуй метод, который возвращает длину строки.

```java
int getLength(String s)
```

| s | результат |
|---|-----------|
| "Hello" | 5 |
| "" | 0 |
| "Java" | 4 |

---

### Задача 2. Первый символ

Реализуй метод, который возвращает первый символ строки.
Если строка пустая — вернуть `'\0'`.

```java
char getFirstChar(String s)
```

| s | результат |
|---|-----------|
| "Hello" | 'H' |
| "Java" | 'J' |
| "" | '\0' |

---

### Задача 3. Последний символ

```java
char getLastChar(String s)
```

| s | результат |
|---|-----------|
| "Hello" | 'o' |
| "Java" | 'a' |
| "" | '\0' |

### Задача 4. Строка в верхний регистр

### Задача 5. Содержит ли подстроку

Реализуй метод, который возвращает `true` если строка содержит подстроку `sub`.

```java
boolean containsSubstring(String s, String sub)
```

| s | sub | результат |
|---|-----|-----------|
| "Hello" | "ell" | true |
| "Hello" | "xyz" | false |
| "Java" | "Java" | true |

### Задача 6. Подстрока

Реализуй метод, который возвращает подстроку от индекса `from` до индекса `to` не включительно.

```java
String getSubstring(String s, int from, int to)
```

| s | from | to | результат |
|---|------|----|-----------|
| "Hello" | 1 | 3 | "el" |
| "Java" | 0 | 2 | "Ja" |
| "World" | 2 | 5 | "rld" |
