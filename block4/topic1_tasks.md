# Задачи — Одномерные массивы

---

### Задача 1. Первый чётный элемент

Реализуй метод, который возвращает первый чётный элемент массива. Если чётных нет — вернуть `0`.

```java
int getFirstEven(int[] numbers)
```

| numbers | результат |
|---------|-----------|
| `[1, 3, 4, 6]` | `4` |
| `[2, 5, 7]` | `2` |
| `[1, 3, 5]` | `0` |

---

### Задача 2. Последний элемент

Реализуй метод, который возвращает последний элемент массива. Если массив пустой — вернуть `0`.

```java
int getLast(int[] numbers)
```

| numbers | результат |
|---------|-----------|
| `[10, 20, 30]` | `30` |
| `[5]` | `5` |
| `[0, 1, 2]` | `2` |
| `[]` | `0` |
