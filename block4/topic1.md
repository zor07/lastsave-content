# Одномерные массивы

В этой теме разберём что такое массив, как его создавать и работать с его элементами.

## Что такое массив

Массив — это структура данных, которая хранит несколько значений одного типа под одним именем. Чтобы обратиться к конкретному элементу, используется индекс — порядковый номер элемента в массиве. Нумерация начинается с нуля, то есть первый элемент имеет индекс 0, второй — 1, и так далее.

```java
int[] numbers = {10, 20, 30, 40, 50};
//               0   1   2   3   4  — индексы
```

## Создание массива

Есть два способа. Первый — сразу с элементами:

```java
int[] numbers = {1, 2, 3, 4, 5};
String[] names = {"Alice", "Bob", "Charlie"};
```

Второй — задать размер, заполнить потом:

```java
int[] numbers = new int[5]; // создан массив из 5 элементов, все равны 0
numbers[0] = 10;
numbers[1] = 20;
```

По умолчанию числовые элементы равны `0`, булевы — `false`, строки — `null`.

Каким бы способом массив не создавался — его размер фиксирован. Это связано с тем, что при создании в памяти выделяется непрерывный блок ячеек нужного размера. Расширить его невозможно — соседние ячейки уже могут быть заняты другими данными. Если нужна коллекция переменного размера — для этого есть другие инструменты, познакомимся с ними позже.

Теперь посмотрим как обращаться к элементам массива.

## Доступ к элементам

```java
int[] numbers = {10, 20, 30};
int first = numbers[0]; // 10
int last  = numbers[numbers.length - 1]; // 30
```

Обращение к несуществующему индексу приводит к ошибке:

```java
int[] numbers = {1, 2, 3};
numbers[5]; // ошибка во время выполнения
```

## Длина массива

```java
int[] numbers = {1, 2, 3, 4, 5};
int len = numbers.length; // 5
```

## Перебор массива

Зная длину и умея обращаться к элементам по индексу, можно пройтись по всему массиву в цикле:

```java
int[] numbers = {10, 20, 30};
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

Если индекс не нужен — есть более короткая запись через for-each:

```java
int[] numbers = {10, 20, 30};
for (int n : numbers) {
    System.out.println(n);
}
```

## Изменение элементов

```java
int[] numbers = {1, 2, 3};
numbers[1] = 99;
// теперь numbers = {1, 99, 3}
```
