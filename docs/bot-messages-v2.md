GitHub подключён, добро пожаловать.

Вот как устроена эта стажировка:

— материал приходит сюда, в чат
— ты изучаешь и нажимаешь Готово
— получаешь задание, делаешь его в репозитории на GitHub
— открываешь Pull Request — я проверяю и даю фидбек
— после фидбека прогресс идёт дальше автоматически

Важно: не забегай вперёд. Даже если тема кажется знакомой — не решай задания из следующих спринтов заранее, это сломает логику автоматических проверок.

Сообщения приходят автоматически раз в минуту, если от тебя не ожидается никакого действия. Если пришло сообщение с кнопкой или ожидается PR — следующее придёт только после твоего ответа.

Задание по примитивам. Склонируй репозиторий, создай новую ветку. Открой файл `src/main/java/com/lastsave/block02/topic01/QuestB2T1.java` — там методы с заглушками `// TODO`. Реализуй каждый метод вместо заглушки, больше ничего не трогай.

Когда готово — запушь ветку и открой Pull Request в ветку main на странице репозитория. Запустятся автоматические тесты. Если что-то упадёт — придёт сообщение с деталями, исправишь и запушишь снова.

Как только тесты пройдут — будет ревью от ИИ. Замечания можно исправить, можно нет — прогресс пойдёт дальше в любом случае.

После ревью замержи PR, подтяни изменения в локальный main и удали рабочую ветку.
