# Сообщения бота — v2

[кнопка] = inline кнопка в Telegram
-> = следующее сообщение

---

GitHub подключён, добро пожаловать.

Вот как устроена эта стажировка:

— материал приходит сюда, в чат
— ты изучаешь и нажимаешь Готово
— получаешь задание, делаешь его в репозитории на GitHub
— открываешь Pull Request — я проверяю и даю фидбек
— после фидбека прогресс идёт дальше автоматически

Важно: не забегай вперёд. Даже если тема кажется знакомой — не решай задания из следующих спринтов заранее, это сломает логику автоматических проверок.

Сообщения приходят автоматически раз в минуту, если от тебя не ожидается никакого действия. Если пришло сообщение с кнопкой или ожидается PR — следующее придёт только после твоего ответа.

Первым делом прими приглашение в репозиторий — оно уже у тебя на GitHub. Без этого задания не получится сдать.

Готов начать? [Поехали]

Второй спринт — основы языка: примитивы, синтаксис, соглашения об именовании. Ссылка на репозиторий была в предыдущем сообщении — прими приглашение если ещё не принял.

->

Начнём с примитивов и базовых типов. Это справочник — не нужно заучивать, просто пробегись. [Готово]

->

Задание по примитивам. Склонируй репозиторий, создай новую ветку, открой файл с заданиями по теме примитивов. Вносить правки нужно только в указанных местах — не трогай остальной код, это сломает автоматические проверки.

Когда всё готово — запушь ветку и открой Pull Request в ветку main на странице репозитория.

После этого запустятся автоматические тесты. Если что-то упадёт — придёт сообщение с деталями, исправишь и запушишь снова. Как только тесты пройдут — будет ревью от ИИ. Замечания по нему можно исправить, можно нет — прогресс пойдёт дальше в любом случае.
