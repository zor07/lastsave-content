# Сюжетная линия бота — анализ и планирование

Бот — персонаж по имени **Аня** (sender: `ANYA`). Технические сообщения шлёт `BOT`.

Каждая секция содержит одно или несколько сообщений. Сообщение ждёт одного из трёх событий:
- `CALLBACK` — студент нажимает кнопку ("Готово")
- `PR` — студент создаёт Pull Request
- `NOTHING` — бот просто показывает сообщение и сразу двигается дальше

## Проблемы и наблюдения

### 1. Нет вводного сообщения о стажировке
Первое сообщение сразу про JDK. Студент не понимает куда попал, кто такая Аня, что его ждёт.

### 2. Аня представляется мужским родом
"Рад видеть" — нужно поправить на "Рада" если Аня — женский персонаж.

### 3. Сообщения про задания безликие
"Открой класс QuestB2T1 в репозитории и реши задания" — шаблонно, без контекста. Не ощущается как живой наставник.

### 4. Нет сообщений для block3–block5
В data.sql только block1 и block2. Всё остальное содержание (строки, массивы, ООП) не имеет сообщений бота.

### 5. Нет реакции после PR ревью
После "PR получен, проверяю..." — непонятно что происходит дальше. Нет сообщения с результатом ревью или переходом к следующей теме.

### 6. Нет разделения на спринты для новых блоков
Block2 начинается с "Новый спринт" — хорошо. Но для последующих блоков этого нет.
