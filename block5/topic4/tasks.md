# Задачи — Пакеты и импорты

В этой задаче тебе нужно **самому создать пакет** внутри уже существующего и разместить в нём несколько классов. Это основная цель раздела — почувствовать, как пакеты устроены на практике.

**Важно:** соблюдай названия пакетов, классов и методов из условия — тесты проверяют по именам.

---

### Задача 1. Person, PersonParser, PersonValidator

У тебя уже есть пакет `com.lastsave.block05.topic04.task01` — в нём находится `Main.java`.

Внутри него создай пакет `persons`. Полное имя пакета будет:

```
com.lastsave.block05.topic04.task01.persons
```

В этом пакете создай три класса.

---

**Класс `Person`**

Поля (оба строковые):
- `name` — имя
- `city` — город

Добавь конструктор, принимающий оба поля, и геттеры `getName()`, `getCity()`.

---

**Класс `PersonParser`**

Один метод:

```java
public Person parse(String input)
```

Метод принимает строку вида `"name, city"`, разбивает её по разделителю `", "` и возвращает новый объект `Person`.

Если строка не соответствует ожидаемому формату — вернуть `null`.

> Подсказка: используй метод `split` класса `String`. Например: `input.split(", ")` вернёт массив частей. Если частей не две — формат неверный.

**Что такое парсер и зачем он нужен**

Парсер — это класс, который умеет превращать данные из одного формата в другой. Чаще всего — из текста в объект. Такой подход очень распространён: данные приходят в виде строки (из файла, из сети, от пользователя), а работать с ними удобнее как с объектом.

В реальных проектах есть целые библиотеки для парсинга — например, JSON-парсеры. Но принцип тот же: взять сырые данные, разобрать по структуре, вернуть объект.

Принято выносить логику парсинга в отдельный класс, а не смешивать её с самой моделью (`Person`). Класс `Person` отвечает за хранение данных, `PersonParser` — за то, как их получить из строки. Это называется разделением ответственности, и ты будешь встречать этот принцип ещё много раз.

---

**Класс `PersonValidator`**

Один **статический** метод:

```java
public static boolean validate(String input)
```

Возвращает `true`, если строка при разбивке по `", "` даёт ровно два элемента. Иначе — `false`.

**Что такое валидация и зачем она нужна**

Валидация — это проверка данных перед тем, как с ними работать. Прежде чем парсить строку, стоит убедиться, что она вообще в нужном формате — иначе парсер получит мусор и сломается.

В реальных приложениях при невалидных данных принято бросать исключение — специальный механизм сигнализации об ошибке. Мы ещё не проходили исключения, поэтому пока делаем проще: метод возвращает `true` или `false`, а вызывающий код сам решает что делать дальше. Это распространённый подход для простых случаев — в Java его можно встретить, например, в методах вроде `String.isEmpty()` или `Character.isDigit()`.

---

После того как классы готовы, в `Main.java` импортируй их из пакета `persons` и проверь вручную:

```java
import com.lastsave.block05.topic04.task01.persons.Person;
import com.lastsave.block05.topic04.task01.persons.PersonParser;
import com.lastsave.block05.topic04.task01.persons.PersonValidator;

System.out.println(PersonValidator.validate("Алекс, Москва")); // true
System.out.println(PersonValidator.validate("Алекс"));          // false

PersonParser parser = new PersonParser();

Person person = parser.parse("Алекс, Москва");
System.out.println(person.getName()); // Алекс
System.out.println(person.getCity()); // Москва

Person invalid = parser.parse("Алекс");
System.out.println(invalid); // null
```
