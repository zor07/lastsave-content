## Пакеты и импорты

В данном материале разберёмся с пакетами и импортами.

Ты наверняка обращал внимание, что во всех созданных тобой классах первой строкой идёт что-то вроде:

```java
package com.lastsave.block05.topic01.task01;
```

Это и есть пакет. По сути — это просто папка (или вложенные папки) в структуре проекта. Пакеты нужны для организации кода: когда классов становится много, держать их всех в одном месте неудобно. Пакеты позволяют группировать связанные классы вместе — точно так же, как папки на компьютере помогают не потерять файлы.

Кроме организации, пакеты влияют на доступ. Помнишь package private из прошлого раздела? Именно пакет определяет границу этого уровня доступа — что видно внутри, а что снаружи.

Пакет на самом деле является частью полного имени класса. Да, всё это время ты использовал короткие имена, а не полные. Полное имя складывается из имени пакета и имени класса. Например:

```
com.lastsave.block05.topic01.task01.Book
```

Технически мы можем использовать классы по их полному имени прямо в коде, без каких-либо дополнительных объявлений:

```java
com.lastsave.block05.topic01.task01.Book book =
    new com.lastsave.block05.topic01.task01.Book("Clean Code", "Robert Martin", 464);
```

Код рабочий. Но писать так каждый раз — мучение. Именно поэтому существуют импорты.

## Импорты

Импорт — это способ сказать компилятору: "я буду использовать этот класс, и хочу обращаться к нему просто по имени, без указания полного пути". После импорта можно писать просто `Book` вместо полного имени:

```java
import com.lastsave.block05.topic01.task01.Book;

Book book = new Book("Clean Code", "Robert Martin", 464);
```

Импорты объявляются в начале файла, после строки с пакетом.

Классы из одного пакета импортировать не нужно — они уже видят друг друга напрямую.

## Неиспользуемые импорты и импорт со звёздочкой

Возможно, ты замечал что IDE иногда подсвечивает серым некоторые строки с импортами. Это неиспользуемые импорты — классы, которые были когда-то нужны, но потом код изменился и они остались висеть. Держать их в файле не стоит: они не ломают код, но засоряют файл и сбивают с толку. IntelliJ IDEA умеет убирать их автоматически — `Ctrl+Alt+O` (или `⌥⌘O` на Mac).

Ещё один вариант который можно встретить — импорт со звёздочкой:

```java
import java.util.*;
```

Такая запись означает "импортировать всё из пакета `java.util`". Это удобно на первый взгляд, но на практике плохо: непонятно какие конкретно классы используются в файле, а IDE и линтеры обычно предупреждают о таком импорте. Лучше всегда импортировать явно — по одному классу.
