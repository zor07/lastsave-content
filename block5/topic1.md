## Классы и объекты

До этого момента весь код жил в статических методах — мы передавали данные через параметры и получали результат. Но Java — объектно-ориентированный язык, и его главная единица — объект.

**Класс** — это описание: какие данные хранит сущность и что с ними можно делать. **Объект** — конкретный экземпляр этого описания в памяти.

Аналогия: класс — это чертёж дома. Объект — конкретный дом, построенный по этому чертежу. По одному чертежу можно построить сколько угодно домов.

```java
public class Car {
    String brand;
    int year;
}
```

Это класс `Car`. Он описывает что у любой машины есть марка и год выпуска. Сам по себе класс ничего не делает — это только шаблон.

## Поля

Переменные внутри класса называются **полями**. Они описывают состояние объекта.

```java
public class Car {
    String brand;
    int year;
    double price;
}
```

Если при создании объекта полю не присвоить значение — оно получит значение по умолчанию: `0` для числовых типов, `false` для `boolean`, `null` для ссылочных типов (строки, объекты).

## Создание объекта

Класс описан — теперь создадим объект. Для этого используется ключевое слово `new`.

```java
Car car = new Car();
car.brand = "Toyota";
car.year = 2020;

System.out.println(car.brand); // Toyota
System.out.println(car.year);  // 2020
```

`new Car()` создаёт новый объект в памяти и возвращает ссылку на него. Обращение к полям — через точку.

Каждый объект хранит свои собственные значения полей:

```java
Car first = new Car();
first.brand = "Toyota";

Car second = new Car();
second.brand = "BMW";

System.out.println(first.brand);  // Toyota
System.out.println(second.brand); // BMW
```

## Методы

Поля хранят состояние, **методы** описывают поведение — что можно сделать с данными объекта.

```java
public class Car {
    String brand;
    int year;

    String getInfo() {
        return brand + ", " + year;
    }
}
```

```java
Car car = new Car();
car.brand = "Toyota";
car.year = 2020;

System.out.println(car.getInfo()); // Toyota, 2020
```

Метод объявляется внутри класса и имеет доступ ко всем полям объекта, на котором вызван.

## Конструктор

Сейчас создание объекта выглядит неудобно: сначала `new Car()`, потом заполняем каждое поле отдельно. Легко забыть присвоить нужное значение.

**Конструктор** — специальный метод, который вызывается при `new` и позволяет сразу передать начальные значения.

```java
public class Car {
    String brand;
    int year;

    Car(String brand, int year) {
        this.brand = brand;
        this.year = year;
    }

    String getInfo() {
        return brand + ", " + year;
    }
}
```

```java
Car car = new Car("Toyota", 2020);
System.out.println(car.getInfo()); // Toyota, 2020
```

Конструктор отличается от обычного метода двумя вещами: имя совпадает с именем класса, и у него нет возвращаемого типа.

Если конструктор не объявлен явно, Java создаёт конструктор по умолчанию — без параметров. Как только объявляешь хотя бы один конструктор — конструктор по умолчанию исчезает.

## this

В примере выше параметр и поле называются одинаково — `brand`. `this` — это ссылка на текущий объект, с её помощью явно указываем что слева поле объекта, а справа — параметр.

```java
Car(String brand, int year) {
    this.brand = brand; // this.brand — поле, brand — параметр
    this.year = year;
}
```

Если имена не совпадают — `this` можно не писать, компилятор разберётся сам. Но когда совпадают — без `this` не обойтись.
