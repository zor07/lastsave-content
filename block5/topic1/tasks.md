# Задачи — Классы и объекты

Каждая задача — отдельный класс. В проекте уже подготовлены папки для каждой задачи.

Найди папку `com/lastsave/block05/topic01` — внутри неё три папки: `task01`, `task02`, `task03`. Каждую задачу необходимо выполнять в своей папке (пакете) — в задании указано, в какой именно.

В каждой папке уже есть файл `package-info.java` — трогать его не нужно, это просто маркер для удобства навигации.

**Важно:** в задании указаны конкретные названия классов, полей и методов. Необходимо использовать именно их — тесты проверяют код по названиям, и если название не совпадёт, тест не пройдёт.

**Важно:** если ты уже знаком с модификаторами доступа (`public`, `private`) — в этих задачах их использовать не нужно. Все поля объявляй без модификатора, методы — с `public`. Иначе тесты не пройдут.

### Задача 1. Класс Book

**Пакет:** `com.lastsave.block05.topic01.task01`

Создай класс `Book`, который описывает книгу.

У книги есть три свойства:
- `title` — название (`String`)
- `author` — автор (`String`)
- `pages` — количество страниц (`int`)

Добавь конструктор, принимающий все три поля.

Добавь метод `getSummary()`, который возвращает строку в формате:
```
title by author, pages pages
```

Примеры:

| title | author | pages | результат |
|-------|--------|-------|-----------|
| `"Clean Code"` | `"Robert Martin"` | `464` | `"Clean Code by Robert Martin, 464 pages"` |
| `"Effective Java"` | `"Joshua Bloch"` | `412` | `"Effective Java by Joshua Bloch, 412 pages"` |

### Задача 2. Класс Rectangle

**Пакет:** `com.lastsave.block05.topic01.task02`

Создай класс `Rectangle`, который описывает прямоугольник.

У прямоугольника есть два свойства:
- `width` — ширина (`int`)
- `height` — высота (`int`)

Добавь **два конструктора**:
- без параметров — создаёт прямоугольник со сторонами 1x1
- с параметрами `width` и `height`

Добавь методы:
- `area()` — возвращает площадь (`int`)
- `perimeter()` — возвращает периметр (`int`)

Примеры:

| конструктор | width | height | area() | perimeter() |
|-------------|-------|--------|--------|-------------|
| `Rectangle(5, 3)` | `5` | `3` | `15` | `16` |
| `Rectangle(4, 4)` | `4` | `4` | `16` | `16` |
| `Rectangle()` | `1` | `1` | `1` | `4` |

### Задача 3. Класс Person

**Пакет:** `com.lastsave.block05.topic01.task03`

Создай класс `Person`, который описывает человека.

У человека есть два свойства:
- `name` — имя (`String`)
- `age` — возраст (`int`)

Добавь конструктор, принимающий оба поля.

Добавь метод `isAdult()`, который возвращает `true` если возраст >= 18, иначе `false`.

Примеры:

| name | age | isAdult() |
|------|-----|-----------|
| `"Alex"` | `25` | `true` |
| `"Maria"` | `17` | `false` |
| `"Ivan"` | `18` | `true` |
