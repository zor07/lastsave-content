# Первый проект: Hello World

## Создание проекта

1. На стартовом экране нажми **New Project**
2. Слева выбери **Java**
3. В поле **JDK** должна стоять версия 21. Если поле пустое — нажми на выпадающий список → **Add JDK** → найди папку куда установил JDK
4. Нажми **Create**

Проект создан. Слева видишь дерево папок — это структура проекта.

---

## Практическая задача

1. В дереве файлов раскрой папку **src**
2. Кликни правой кнопкой на **src** → **New → Java Class**
3. Назови класс `Main` и нажми Enter
4. Вставь этот код:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

5. Нажми зелёную кнопку ▶️ рядом со словом `main`
6. Внизу появится панель **Run** — там должна быть строка `Hello, World!`

Если видишь её — среда настроена, урок завершён. Отправляй код на ревью.
