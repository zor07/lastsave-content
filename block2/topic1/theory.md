## Комментарии

Комментарий — это текст в коде, который компилятор игнорирует. Нужен для пояснений себе и другим.

```java
// Однострочный комментарий — всё после // до конца строки

int age = 25; // можно в конце строки с кодом

/*
   Многострочный комментарий.
   Всё между /* и */ игнорируется.
*/

/**
 * Javadoc-комментарий — для документирования методов и классов.
 * IDE показывает его как подсказку при наведении.
 */
```

В этом справочнике комментарии используются для пояснений прямо в коде — как раз вместо текста рядом с примером.

## Переменные

Переменная — это именованная ячейка памяти. Сначала объявляем (указываем тип и имя), потом используем.

```java
int age;          // объявление
age = 25;         // присваивание

int score = 100;  // объявление + присваивание в одну строку
```

Тип нужно указать один раз — при объявлении. Потом тип уже не меняется.

```java
int x = 5;
x = 10;   // ок — меняем значение
x = "hi"; // ошибка компиляции — тип изменить нельзя
```

**`var` — сокращённая запись (Java 10+)**

Компилятор сам выводит тип из значения справа. Удобно, но не злоупотребляй — код должен оставаться читаемым.

```java
var name = "Alice";  // компилятор понимает: String
var count = 42;      // компилятор понимает: int
```

⚠️ `var` работает только внутри метода — для локальных переменных. Что такое метод — читай в topic2.

## Примитивные типы

В Java у каждой переменной есть тип. Примитивы — это базовые встроенные типы, не объекты. Их восемь, но на практике чаще всего нужны четыре.

| Тип | Что хранит | Пример |
|-----|-----------|--------|
| `int` | Целое число (−2 млрд .. +2 млрд) | `int age = 25;` |
| `long` | Большое целое число | `long population = 8_000_000_000L;` |
| `double` | Дробное число | `double price = 9.99;` |
| `boolean` | `true` или `false` | `boolean isActive = true;` |
| `char` | Один символ | `char grade = 'A';` |
| `byte` | Целое −128 .. 127 | `byte b = 100;` |
| `short` | Целое −32768 .. 32767 | `short s = 1000;` |
| `float` | Дробное, меньше точность чем double | `float f = 3.14f;` |

На практике пользуйся `int`, `long`, `double`, `boolean`. Остальные встретишь редко — знай что существуют.

```java
int count = 10;
double ratio = 3.14;
boolean done = false;
long bigNumber = 10_000_000_000L; // L обязателен для long-литералов
```

Отдельно стоит `String` — строка. Это не примитив, это объект, но используется повсеместно:

```java
String name = "Alice";
```
