# Синтаксис: операторы, условия, циклы, методы

## Арифметические операторы

| Оператор | Описание | Пример | Результат |
|----------|----------|--------|-----------|
| `+` | Сложение | `3 + 2` | `5` |
| `-` | Вычитание | `5 - 3` | `2` |
| `*` | Умножение | `4 * 3` | `12` |
| `/` | Деление | `7 / 2` | `3` ⚠️ |
| `%` | Остаток от деления | `7 % 2` | `1` |

⚠️ **Целочисленное деление.** Если оба операнда — целые числа (`int`), результат тоже целый. Дробная часть отбрасывается, не округляется.

```java
int a = 7 / 2;      // 3, а не 3.5
double b = 7.0 / 2; // 3.5 — один операнд double, результат double
```

**`%` — остаток от деления.** Часто используется чтобы проверить чётность или ограничить диапазон значений.

```java
10 % 3  // 1
8 % 2   // 0 — делится нацело
```

**Инкремент и декремент** — увеличить или уменьшить значение на 1.

```java
int x = 5;
x++;  // x = 6
x--;  // x = 5

// Разница между x++ и ++x важна только когда используешь значение в выражении
int a = 5;
int b = a++;  // b = 5, a = 6 (сначала присвоили, потом увеличили)
int c = ++a;  // c = 7, a = 7 (сначала увеличили, потом присвоили)
```

Разница между `x++` и `++x` проявляется когда используешь их внутри выражения: `x++` сначала возвращает текущее значение, потом увеличивает; `++x` сначала увеличивает, потом возвращает.

```java
int x = 1;
System.out.println(x++); // 1 — выводится старое значение, x становится 2
System.out.println(++x); // 3 — x сначала становится 3, потом выводится
System.out.println(x);   // 3
```

## Операторы сравнения

Результат сравнения — всегда `boolean`: `true` или `false`.

| Оператор | Описание | Пример | Результат |
|----------|----------|--------|-----------|
| `==` | Равно | `5 == 5` | `true` |
| `!=` | Не равно | `5 != 3` | `true` |
| `>` | Больше | `5 > 3` | `true` |
| `<` | Меньше | `3 < 5` | `true` |
| `>=` | Больше или равно | `5 >= 5` | `true` |
| `<=` | Меньше или равно | `3 <= 5` | `true` |

```java
int age = 20;
boolean isAdult = age >= 18;  // true
boolean isNegative = age < 0; // false
```

⚠️ **`==` для объектов работает иначе.** Для примитивов (`int`, `double`, `boolean`) — сравнивает значения. Для объектов (`String` и всё остальное) — сравнивает ссылки, а не содержимое. Подробнее разберём в теме про сравнение объектов. Пока просто знай: строки сравнивай через `.equals()`.

```java
String a = "hello";
String b = "hello";
a == b      // может быть true, а может false — не надёжно
a.equals(b) // всегда true — сравнивает содержимое
```

## Логические операторы

Используются для объединения условий. Работают с `boolean` значениями.

| Оператор | Описание | Пример |
|----------|----------|--------|
| `&&` | И (оба должны быть true) | `age > 18 && hasTicket` |
| `\|\|` | ИЛИ (хотя бы одно true) | `isAdmin \|\| isModerator` |
| `!` | НЕ (инверсия) | `!isBlocked` |

```java
int age = 20;
boolean hasTicket = true;

boolean canEnter = age >= 18 && hasTicket;  // true
boolean needsHelp = age < 10 || age > 90;   // false
boolean isNotBlocked = !false;               // true
```

**`&&` и `||` — ленивые (short-circuit evaluation).** Если результат уже известен по первому операнду — второй не вычисляется.

```java
// Если x == 0, второе условие не проверяется — деления на ноль не будет
if (x != 0 && 100 / x > 5) { ... }
```

Это не просто оптимизация — на этом строят защиту от ошибок.

## Операторы присваивания

Сокращённая запись для "взять текущее значение, сделать операцию, записать обратно".

| Оператор | Эквивалент | Пример |
|----------|------------|--------|
| `=` | — | `x = 5` |
| `+=` | `x = x + n` | `x += 3` |
| `-=` | `x = x - n` | `x -= 2` |
| `*=` | `x = x * n` | `x *= 4` |
| `/=` | `x = x / n` | `x /= 2` |
| `%=` | `x = x % n` | `x %= 3` |

```java
int score = 10;
score += 5;  // score = 15
score *= 2;  // score = 30
score -= 10; // score = 20
```

## Управление потоком выполнения кода

### if / else

```java
if (условие) {
    // выполняется если условие true
} else if (другое_условие) {
    // выполняется если первое false, а это true
} else {
    // выполняется если все условия выше false
}
```

```java
int score = 75;

if (score >= 90) {
    System.out.println("Отлично");
} else if (score >= 70) {
    System.out.println("Хорошо");
} else {
    System.out.println("Нужно подтянуться");
}
```

**Лишний `else` после `return`** — частая лишняя конструкция:

```java
// Многословно
if (score >= 90) {
    return "Отлично";
} else {
    return "Не отлично";
}

// Чище
if (score >= 90) {
    return "Отлично";
}
return "Не отлично";
```

### Тернарный оператор

Короткая форма `if/else` для присваивания значения.

```java
тип переменная = условие ? значение_если_true : значение_если_false;
```

```java
int age = 20;
String status = age >= 18 ? "взрослый" : "несовершеннолетний";
```

Уместен когда выражение простое и читается легко. Не надо вкладывать тернарные операторы друг в друга — это нечитаемо.

### switch

Используется когда нужно выбрать действие из нескольких вариантов по конкретному значению.

**Классический switch:**

```java
int day = 3;

switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    case 3:
        System.out.println("Среда");
        break;
    default:
        System.out.println("Другой день");
}
```

⚠️ **Fall-through — самая частая ошибка в switch.** Если забыть `break`, выполнение "проваливается" в следующий `case`.

```java
int x = 1;
switch (x) {
    case 1:
        System.out.println("один");
        // нет break!
    case 2:
        System.out.println("два"); // тоже выполнится!
    case 3:
        System.out.println("три"); // и это тоже!
}
// Вывод: один, два, три
```

**Switch expression (Java 14+)** — современный синтаксис. Нет fall-through, можно присвоить результат.

```java
int day = 3;
String name = switch (day) {
    case 1 -> "Понедельник";
    case 2 -> "Вторник";
    case 3 -> "Среда";
    default -> "Другой день";
};
```

Предпочитай этот вариант — он безопаснее и короче.

### Циклы

**`while` — пока условие выполняется:**

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
// Выведет: 0 1 2 3 4
```

Используй когда не знаешь заранее сколько итераций нужно.

---

**`do-while` — выполняется хотя бы один раз:**

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);
```

Отличие от `while`: тело выполняется сначала, потом проверяется условие. Встречается редко, но знать нужно.

---

**`for` — когда знаешь количество итераций:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

Три части заголовка: `инициализация; условие; шаг`. Все три можно менять:

```java
for (int i = 10; i > 0; i -= 2) {
    System.out.println(i); // 10, 8, 6, 4, 2
}
```

---

**`for-each` — перебор элементов массива или коллекции:**

```java
int[] numbers = {1, 2, 3, 4, 5};

for (int number : numbers) {
    System.out.println(number);
}
```

Короче и читаемее обычного `for`, когда индекс не нужен. Подробнее про массивы — в следующих темах.

### break и continue

**`break`** — немедленно выходит из цикла:

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break; // выходим когда дошли до 5
    }
    System.out.println(i); // выведет 0 1 2 3 4
}
```

**`continue`** — пропускает текущую итерацию и переходит к следующей:

```java
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue; // пропускаем 2
    }
    System.out.println(i); // выведет 0 1 3 4
}
```

⚠️ **`break` выходит только из ближайшего цикла.** Если циклы вложены — выйдет только из внутреннего:

```java
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break; // выходит из внутреннего цикла, внешний продолжается
    }
}
```

## Методы

Метод — это именованный блок кода, который можно вызвать по имени. Нужен чтобы не повторять одно и то же, и чтобы разбивать программу на логические части.

**Объявление метода:**

```java
тип_возвращаемого_значения имяМетода(тип параметр1, тип параметр2) {
    // тело метода
    return результат;
}
```

```java
int add(int a, int b) {
    return a + b;
}
```

**Вызов метода:**

```java
int result = add(3, 5); // result = 8
```

**`void`** — если метод ничего не возвращает:

```java
void printGreeting(String name) {
    System.out.println("Привет, " + name + "!");
}
```

**`return`** делает две вещи: возвращает значение и завершает выполнение метода. Код после `return` не выполняется.

```java
int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

**Параметры** — это входные данные метода. Они живут только внутри метода.

```java
void greet(String name) { // name — параметр
    System.out.println("Привет, " + name);
}

greet("Алиса"); // "Алиса" — аргумент (конкретное значение)
greet("Боб");
```

**Перегрузка (overloading)** — можно создать несколько методов с одним именем, но разными параметрами. Компилятор сам выберет нужный по типу аргументов.

```java
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

## Структура класса

В Java весь код находится внутри класса. Пока не углубляемся в ООП — просто нужно понимать минимум, чтобы код компилировался.

```java
public class Main {

    public static void main(String[] args) {
        // Точка входа в программу
        // JVM запускает именно этот метод
        System.out.println("Hello, World!");
    }

    static int add(int a, int b) {
        return a + b;
    }
}
```

**`public class Main`** — объявление класса. Имя файла должно совпадать с именем класса: `Main.java`.

**`main`** — специальный метод, с которого начинается выполнение программы. Сигнатура должна быть точно такой: `public static void main(String[] args)`.

**`static`** — означает что метод принадлежит классу, а не объекту. Пока просто знай: методы которые вызываются из `main` напрямую, тоже должны быть `static`. Почему — разберём это позже, когда дойдём до ООП.

```java
public class Main {

    public static void main(String[] args) {
        int result = add(3, 5);
        System.out.println(result);
    }

    static int add(int a, int b) {
        return a + b;
    }
}
```

## Шпаргалка: типичные ошибки

| Ошибка | Как выглядит | В чём проблема |
|--------|-------------|----------------|
| `=` вместо `==` | `if (x = 5)` | Присваивание вместо сравнения |
| Забытый `break` в switch | `case 1: ... case 2:` | Fall-through, выполнятся все ветки подряд |
| Целочисленное деление | `int x = 7 / 2` | Результат `3`, а не `3.5` |
| `==` для строк | `str == "hello"` | Сравнивает ссылки, используй `.equals()` |
| `break` во вложенном цикле | вложенные `for` | Выходит только из внутреннего цикла |
| Off-by-one | `i <= array.length` | Выход за границы массива |
