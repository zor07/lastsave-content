# Задачи — Примитивы и базовые типы

### Задача 1. Сумма двух чисел

Реализуй метод, который принимает два целых числа и возвращает их сумму.

```java
int sum(int a, int b)
```

| a | b | результат |
|---|---|-----------|
| 3 | 5 | 8 |
| -2 | 7 | 5 |
| 0 | 0 | 0 |

### Задача 4. Перевод температуры

Реализуй метод, который переводит температуру из Цельсия в Фаренгейт.

Формула: `F = C * 9.0 / 5 + 32`

```java

```

| celsius | результат |
|---------|-----------|
| 0.0 | 32.0 |
| 100.0 | 212.0 |
| -40.0 | -40.0 |
