### Задача 1. Оценка по баллам

Реализуй метод, который по числовому баллу возвращает текстовую оценку.

```java
String getGrade(int score)
```

| score | результат |
|-------|-----------|
| 95 | "Отлично" |
| 75 | "Хорошо" |
| 55 | "Удовлетворительно" |
| 30 | "Неудовлетворительно" |

Шкала:
- 90–100 → "Отлично"
- 70–89 → "Хорошо"
- 50–69 → "Удовлетворительно"
- 0–49 → "Неудовлетворительно"

### Задача 7. Степень числа

### Задача 10. Числа Фибоначчи

Реализуй метод, который возвращает `n`-е число Фибоначчи.

Последовательность: 0, 1, 1, 2, 3, 5, 8, 13, 21, ...
- `fibonacci(0)` = 0
- `fibonacci(1)` = 1
- `fibonacci(n)` = fibonacci(n-1) + fibonacci(n-2)

Реализуй через цикл, не через рекурсию.

```java
int fibonacci(int n)
```

| n | результат |
|---|-----------|
| 0 | 0 |
| 1 | 1 |
| 6 | 8 |
| 10 | 55 |
